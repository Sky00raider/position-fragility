\section{Method}
\label{sec:method}

\subsection{Task and data}
We use MuSiQue-Ans v1.0~\cite{musique}, whose questions are composed from single-hop questions, each with a gold intermediate answer and a supporting paragraph. We keep answerable questions with $K\in\{3,4\}$ hops from the train and dev splits (dev: 760 three-hop and 405 four-hop; train: 4{,}387 and 1{,}175). Two-hop questions are excluded because they have only one intermediate hop. Because the method is inference-only, train items are usable; we report the split of every item and compare results across splits.

MuSiQue composes hops in five shapes. In the \emph{linear} shapes (3hop1, 4hop1) every hop consumes the previous answer. In the \emph{branching} shapes (3hop2, 4hop2, 4hop3) some hops are independent and are merged later. We read each hop's dependencies from the \texttt{\#N} references in the gold decomposition. Linear chains are our primary analysis set; all items form a robustness check.

\textbf{Context.} Each item is shown its gold supporting paragraphs plus four fixed non-supporting paragraphs (distinct titles, none sharing a title with a gold paragraph), sampled with a per-item seed and shuffled with the same seed, so every model and condition sees the identical context.

\subsection{Prompt and own-chain baseline}
All models receive the same instruction (Fig.~\ref{fig:prompt}), asking for one line per hop, \texttt{Hop N: <sub-question> -> <answer>}, followed by \texttt{Final answer: <short answer>}. Prompts are built with each model's own chat template. For each item we generate the model's \emph{own} chain (one sample) and a \emph{closed-book} answer (same instruction without paragraphs).

\textbf{Eligibility.} An item enters the injection study only if its own chain (i)~gives a correct final answer (exact match after SQuAD normalization~\cite{squad} against the answer and its aliases), (ii)~contains exactly $K$ hop lines numbered $1..K$, (iii)~matches the gold decomposition hop by hop, in order (after removing parenthetical remarks, each hop answer has normalized exact match or token-F1 $\ge 0.8$ with the gold hop answer, or contains it as whole words with at most three extra words; the final hop is also checked against the answer aliases), (iv)~is not truncated, and (v)~the closed-book answer is wrong, which removes items the model can answer from memory. Every failed criterion is logged per item. Requirement (iii) guarantees that the hop we corrupt is the hop the gold decomposition says it is, which is what makes the error position exact.

\subsection{Conditions}
For an eligible item with $K$ hops we run:
\begin{itemize}
\item \textbf{noprefix}: the original prompt, a fresh sample; it defines item difficulty.
\item \textbf{clean$_k$}, $k=1..K$: the model's own chain truncated after hop line $k$, then resumed.
\item \textbf{inject$_k$}, $k=1..K$, for each of two error types: as clean$_k$, but the answer on hop line $k$ is replaced by a planted value.
\end{itemize}
This gives $1+3K$ cells per item (10 for $K{=}3$, 13 for $K{=}4$) before validity drops. Hop $K$ produces the final answer; corrupting it is analyzed separately as the \emph{terminal} step and is never pooled with ``late'' intermediate hops.

\subsection{Injection by assistant-turn prefill}
Corruptions are applied to the model's own text, not to a gold template. The prefix is the model's own answer text cut at the end of hop line $k$, with only the answer span after the arrow on that line replaced; it ends in exactly one newline. The prefix is appended after the chat template's assistant header, so the model continues its own turn: no new user turn is opened and no end-of-turn token is placed at the splice. For Qwen3 in non-thinking mode the template's empty think block precedes the prefix; in thinking mode the prefix is placed inside the think block (\texttt{<think>\textbackslash n} + hop lines), and the model continues in hop format inside the think block before it answers (confirmed in the pilot). \tbd{describe the think\_trace injection site if its run succeeds.}

Prompt text is tokenized once, without adding special tokens, and the identical token ids are passed to the inference engine. Unit tests check, for every tokenizer used, that the spliced ids contain no end-of-turn token after the template, that the template tokens are unchanged by the splice, and that Llama receives exactly one BOS token.

\subsection{Error types}
Every hop answer receives a type tag: regular expressions for years, five date formats and plain numbers; otherwise the spaCy (\texttt{en\_core\_web\_sm})~\cite{spacy} entity label of the answer's mention in its supporting paragraph. Candidate values are kept only when their in-context label agrees with the label of the string on its own (covering the whole string), which removes many small-model mistags.
\begin{itemize}
\item \textbf{In-context distractor}: a string of the same type from the item's four \emph{shown} distractor paragraphs (titles preferred, then named entities and years). It looks supported by the context.
\item \textbf{Off-context swap}: a gold hop answer of the same type from a \emph{different} MuSiQue item that occurs nowhere in this item's question or shown paragraphs, preferring answers to the same relation (e.g., \emph{place of birth}). It is supported by nothing in the context.
\end{itemize}
Within these pools candidates are ranked by length similarity to the original answer, with a seeded tie-break per item and hop.

\subsection{Validity rules}
A planted value is used only if all hold, otherwise the next candidate is tried; cells with no valid candidate are dropped and logged with the failing rule:
(1)~after normalization it is not equal to, a substring of, or a superstring of any gold answer, alias, or gold hop answer of the item;
(2)~its type tag equals the original's;
(3)~its format matches (year vs.\ year, digits vs.\ none, casing style, trailing punctuation);
(4)~it does not already occur in the model's own baseline output.
Two authors independently audited 100 planted values (25 per error type and $K$) for type match and plausibility: \tbd{agreement, Cohen's $\kappa$, \% type-correct and plausible per error type}.

\subsection{Outcomes}
The final answer is the text after the last \texttt{Final answer:} in the answer part of the output (after \texttt{</think>} in thinking mode); a missing final answer or a truncated run counts as wrong.
\textbf{Correct} (primary) is exact match against the answer and aliases. \textbf{Adopted} is exact match against the planted value; we deliberately do not count mere mentions of the planted value, which fire on restatement. As a secondary measure for verbose answers we also report containment of the gold (resp.\ planted) value within the final-answer line only.

\textbf{Recovery with clean-twin conditioning.} Resumption itself can fail, so we measure recovery only where the uncorrupted resume succeeds:
\begin{equation}
\RR(k) = P\left(\text{inject}_k \text{ correct} \mid \text{clean}_k \text{ correct}\right).
\end{equation}
\textbf{Position sensitivity} on intermediate hops is
\begin{equation}
\PSI = \RR_{\text{late}} - \RR_{\text{early}},
\end{equation}
with early $k{=}1$ and late $k{=}K{-}1$ ($k{=}2$ for $K{=}3$, $k{=}3$ for $K{=}4$). $\PSI>0$ means early errors propagate more.

\textbf{Remaining steps.} For hop $k$, \emph{remaining} is the number of later hops that depend on it directly or transitively; on linear chains this equals $K-k$. Relative position is $k/K$. Because $k$ + remaining $=K$ on linear chains, position, remaining steps and chain length cannot all be varied independently. We therefore compare \emph{matched-remaining} cells, (K3,k2) vs.\ (K4,k3) with one step left and (K3,k1) vs.\ (K4,k2) with two, where absolute position differs but remaining steps are equal (the pairs also differ by one hop in $K$), and we include item difficulty as a covariate.

\section{Experimental Setup}
\label{sec:setup}

\subsection{Models and inference}
\textbf{Qwen3-8B}~\cite{qwen3}, 4-bit AWQ~\cite{awq} (\texttt{Qwen/Qwen3-8B-AWQ}, revision \texttt{4da05a8}), run with \texttt{enable\_thinking} off and on. Same weights in both modes, so the comparison isolates the thinking mode.
\textbf{Llama-3.1-8B-Instruct}~\cite{llama3}, 4-bit AWQ (\texttt{hugging-quants/Meta-Llama-3.1-8B-Instruct-AWQ-INT4}, revision \texttt{db1f81a}), non-thinking only.
Inference uses vLLM~\cite{vllm} 0.32.0 on one RTX 5070 (12\,GB), with an 8{,}192-token context. Each model--mode pair runs on one GPU for all of its conditions.

\textbf{Decoding} (Table~\ref{tab:decoding}) follows each model's recommended sampling settings and is identical across all conditions within a model--mode pair. Closed-book runs cap generation at 512 tokens in non-thinking mode. In the main runs, 3\% of thinking baselines were truncated (and excluded), and no condition cell had more than 3\% of its continuations truncated.

\subsection{Item counts}
Table~\ref{tab:counts} gives the yield. Non-thinking runs attempt all 6{,}727 three- and four-hop items. The thinking run attempts 600 three-hop items and all 1{,}580 four-hop items, oversampling four-hop items because of their low pilot yield. Most items fail eligibility because the final answer is wrong or the chain takes a route other than MuSiQue's decomposition. Four-hop items rarely pass without thinking, so four-hop non-thinking contrasts are underpowered, far below the 300--400 items per $K$ targeted by the power analysis.

\subsection{Statistical analysis}
All confidence intervals are item-clustered percentile bootstraps (items resampled with replacement, 2{,}000 replicates). We report:
\begin{itemize}
\item $\RR$ per model $\times$ mode $\times K \times k \times$ error type, terminal hop in separate rows;
\item $\PSI$ per model $\times$ mode $\times$ error type $\times K$ with 95\% CIs; a position effect is declared \emph{absent} if the 90\% CI lies within $\pm5$ percentage points (equivalent to two one-sided tests at $\alpha=0.05$);
\item exact McNemar tests on paired early vs.\ late outcomes of the same item (both clean twins correct), per model $\times$ mode $\times$ error type $\times K$, Holm-adjusted across these tests;
\item matched-remaining contrasts on linear chains (items resampled independently within each $K$);
\item terminal vs.\ pooled intermediate recovery;
\item one logistic regression on intermediate inject cells with a correct clean twin,
\[
\text{correct} \sim \text{rel\_pos}\times\text{mode} + \text{remaining} + K + \text{error\_type} + \text{difficulty} \,(+\, \text{model}),
\]
with standard errors clustered by item and variance inflation factors reported, since rel\_pos, remaining and $K$ are partly collinear by construction.
\end{itemize}
Primary results use linear chains; all-item results and results excluding truncated runs are reported as robustness checks, since a truncated run counts as wrong and truncation could differ by position. Before the main runs we ran a pilot of 50 dev items per mode and required clean-twin accuracy of about 90\% (lower would mean resumption itself is broken). In the pilot, clean twins were correct in 7/7 non-thinking and 31/32 thinking cells. In the main runs the thinking mode fell below this target (Section~\ref{sec:results}).

\section{Results}
\label{sec:results}
Unless stated otherwise, numbers are for linear chains, $\RR$ is conditioned on a correct clean twin, and brackets give 95\% item-bootstrap CIs. All-item results agree in sign and size with every linear result below. Truncation is below 3\% in every cell, and excluding truncated runs changes no $\PSI$ by more than 0.003. Four-hop non-thinking sets are small (33 linear items for Qwen3, 15 for Llama), so their contrasts have wide intervals.

\subsection{Resumption without an error (clean twins)}
\label{sec:res-twins}
Resuming from the model's own uncorrupted prefix succeeds at 96--100\% of intermediate hops for Qwen3 without thinking and 82--87\% for Llama ($K{=}3$). For Qwen3 with thinking it succeeds at only 68--86\% (terminal hop: 100\%), below the $\approx$90\% target set before the runs. An audit of all failing twins found no scoring error: the gold answer never appears as a final answer. Instead, in thinking mode 80\% of failing twins leave the model's own chain at a later hop and 21\% give the right entity at a different granularity (``1991'' for \emph{December 25, 1991}); the other two runs show similar proportions. The cause in thinking mode is the prefix itself. With hop lines placed inside the think block, Qwen3 treats reasoning as finished: all 985 intermediate clean continuations contain only hop lines and a final answer, with a median of 110 generated tokens against 1{,}231 for an unprefixed resample. The prefill also costs accuracy in thinking mode (clean twin wrong and resample of the same item right in 183 cells vs.\ the reverse in 68; McNemar $p=2\times10^{-13}$) but not without thinking ($p=0.22$ for Qwen3). Thinking-mode $\RR$ is therefore measured on items the model can finish without further deliberation, and its continuations are short (Section~\ref{sec:res-thinking}).

\subsection{RQ1: Position of an intermediate error}
Late intermediate errors are recovered \emph{less} often than early ones, the opposite of H1 (Fig.~\ref{fig:recovery}, Table~\ref{tab:psi}). $\PSI$ is negative in all 12 model $\times$ mode $\times$ error type $\times K$ cells, and its CI excludes zero in 8; the four exceptions are the small four-hop non-thinking sets and one thinking cell whose CI reaches zero. The effect is clearest for Qwen3 without thinking at $K{=}3$, where recovery drops from 0.62 to 0.48 (in-context) and from 0.70 to 0.50 (off-context). In paired items, recovery at the early hop but not the late hop occurs 148 and 195 times, against 59 and 53 for the reverse (Holm-adjusted McNemar $p<10^{-8}$). Llama shows the same pattern at $K{=}3$ ($\PSI=-0.09$ and $-0.13$; McNemar $p_\text{Holm}=0.001$ for off-context). With thinking, $\PSI$ is $-0.09$ to $-0.12$, but its paired tests do not survive Holm adjustment (98--113 pairs per cell). No cell meets the $\pm$5\,pp equivalence criterion. The direction matches the late-stage fragility reported by ASCoT~\cite{ascot} and contradicts the early-error account~\cite{vonrecum,jiamu}.

\subsection{RQ2: Position or remaining steps?}
The data cannot separate position from remaining steps. In the matched-remaining contrasts (same number of later hops, different absolute position), Qwen3 without thinking shows differences of $-0.04$ to $+0.05$, consistent with remaining steps driving the effect, but the CIs span about $\pm0.17$ because the four-hop cells hold about 32 items. With thinking the differences range from $-0.10$ to $+0.04$; one of the four CIs excludes zero. Llama's four-hop cells (13--15 items) are uninformative. In the regression (Table~\ref{tab:logit}), relative position keeps a negative coefficient with remaining steps and $K$ in the model ($\beta=-3.67$, $p=0.023$), while remaining steps ($\beta=-0.58$, $p=0.27$) and $K$ ($p=0.44$) do not. The variance inflation factors of relative position and remaining steps are 87 and 104, so this split of the effect is not reliable. We therefore read the position effect as consistent with, but not separable from, the number of steps left after the error.

\subsection{RQ3: The terminal step}
Errors at the terminal hop are almost never recovered without thinking: $\RR$ is 0.02 and 0.00 for Qwen3 (in-/off-context) and 0.15 and 0.07 for Llama, against 0.56--0.64 at intermediate hops of the same models. The models copy the corrupted last-hop answer into the final answer (Qwen3 adopts the planted value in 98--99\% of terminal cells, Llama in 75--88\%). With thinking, terminal recovery is 0.60 for both error types, still 0.22 below intermediate hops (CIs $-0.29$ to $-0.15$). Pooling the terminal hop with ``late'' hops would therefore make late errors look far more harmful than the intermediate-hop contrast shows.

\subsection{RQ4: Thinking mode}
\label{sec:res-thinking}
Thinking raises recovery at every hop: intermediate $\RR$ is 0.83 and 0.82 with thinking against 0.56 and 0.60 without (in-/off-context; mode $\beta=+1.52$, $p<0.001$). It does not change the shape: the relative position $\times$ mode interaction is small and not significant ($\beta=-0.24$, $p=0.66$), and late errors remain more harmful with thinking (Table~\ref{tab:psi}). Because eligibility differs between modes, we repeated the comparison on the 83 linear items eligible in both (63 three-hop, 20 four-hop). There, thinking still raises recovery on the same cells (intermediate $+0.24$ [0.17, 0.31]; terminal $+0.70$ [0.63, 0.78]), and the terminal hop stays below intermediate hops in both modes. Without thinking $\PSI$ stays negative ($K{=}3$: $-0.14$ and $-0.28$), but with thinking it shrinks to $0.00$ and $-0.10$ with CIs that include zero. The interaction remains non-significant ($p=0.34$) on this smaller set, so the shared items neither confirm nor rule out a change of shape.

These comparisons concern a thinking mode in which the model barely deliberates after the error (Section~\ref{sec:res-twins}): most recoveries happen when the model restates the chain after \texttt{</think>}, rewriting the corrupted hop with the correct entity. \tbd{think\_trace: error planted mid-thought in the model's own thinking trace; continuation length, clean-twin accuracy, $\RR$ and $\PSI$ vs.\ the summary-prefill condition. If continuations stay short, state the summary-prefill result as ``thinking format without post-error deliberation'' and move this to Limitations.}

\subsection{RQ5: Error type}
Off-context swaps, which nothing in the context supports, are recovered slightly more often than in-context distractors ($\beta=+0.15$, $p=0.002$; e.g., Qwen3 without thinking at $K{=}3$, $k{=}1$: 0.70 vs.\ 0.62). The difference is small next to the effects of position, the terminal hop and thinking. With thinking it is inconsistent in sign, and at Llama's terminal hop it reverses (0.15 in-context vs.\ 0.07 off-context).

\subsection{How recovery happens}
Recovery is almost always silent. A rule-based labeler calls a recovery \emph{explicit} if a doubt or correction marker (e.g., ``wait'', ``actually'', ``incorrect'', ``should be'') occurs in the same or the next sentence as the planted or the true hop value, and \emph{silent} otherwise. It marks none of Qwen3's non-thinking recoveries and 0.2\% of its thinking recoveries as explicit; Llama flags the error in 9\% of its intermediate-hop recoveries. Typically the model simply writes the correct entity in a later hop or in its restated chain, without commenting on the planted value. Doubt markers do not indicate success: Llama uses them more often when it fails (15\%) than when it recovers (12\%). These labels are rule-based and were not validated by hand beyond spot checks.
